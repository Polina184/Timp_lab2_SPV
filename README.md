# Вариант 12 — Остаток повторных попыток

Диспетчер подсчитывает, сколько повторных запусков ещё допустимо для набора заданий.

attempts — уже использованные попытки, limit — неотрицательный лимит на одно задание. Вклад записи равен max(0, limit - attempts[i]); attempts неотрицательны и могут превышать limit. Суммировать вклады всех записей.

В текущей версии ошибки исправлены. Исходная версия с ошибками сохранена
в ветке `review-base`. Замечания и исправления описаны в `review.md` и `resolution.md`.

Запуск: dotnet run --project ReviewLab.csproj

- T01: Обычный; ожидается [5].
- T02: Другой лимит; ожидается [4].
- T03: Лимит превышен; ожидается [0].
- T04: Сумма; ожидается [4].
- T05: Пустой; ожидается [0].

Для запуска требуется .NET SDK 9.0 или новее с поддержкой целевой платформы .NET 9.
Дополнительные тесты U01–U04 проверяют другой лимит, границу лимита,
нулевой лимит и неизменность массива при повторном вызове.
Успешный запуск: девять PASS, `Failed: 0`.
